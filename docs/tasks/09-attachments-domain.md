# 09 — Attachments domain (Attachment, lifecycle)

Goal: Pure domain model for attachment metadata + lifecycle states; raw bytes never in domain or PG.

## Checklist

- [ ] `Attachment` entity: id, uploader_user_id, task_id (nullable), storage_provider, bucket_name, object_key, original_filename, mime_type, file_size, lifecycle_status, expires_at, timestamps.
- [ ] Lifecycle states: Received, Uploaded, PendingMetadata, Attached, Rejected, Expired, Orphaned, CleanupPending, Deleted, RejectedByValidation.
- [ ] Valid transitions only (guard illegal moves).
- [ ] `task_id` nullable while pending approval.
- [ ] Object key generated by app/adapter — never derived solely from filename.
- [ ] Domain never holds image bytes or presigned URLs.
- [ ] Unit tests for legal/illegal lifecycle transitions.
