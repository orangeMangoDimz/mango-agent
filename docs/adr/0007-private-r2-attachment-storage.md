# ADR-07 — Private Cloudflare R2 attachment storage

## Context

Images must be stored durably without putting raw bytes in PostgreSQL, and access must stay private and authorized. SDD §16.4, §18, §22.2.

## Decision

Use a **private Cloudflare R2 bucket**. PostgreSQL stores only metadata and the stable R2 object key. Object keys are generated by the application/storage adapter (never the original filename). Access is via short-lived presigned URLs generated only after authorization.

## Consequences

- No raw image bytes or temporary presigned URLs in PostgreSQL (invariant).
- Original filename retained only as metadata; extensions not trusted (SDD §22.4).
- Malware scanning is a future defense if broader file types are introduced.
